# Проверка требований ДЗ Light

| Требование | Результат |
|---|---|
| Готовый Open-Meteo MCP | `tools/list` вернул 12 инструментов с `weather.chukai.io/mcp` через официальный TypeScript SDK и Streamable HTTP |
| Облачный Tool Calling | В браузере подтверждена цепочка OpenAI Chat Completions → `geocode_location` → `get_weather_forecast` → ответ OpenAI |
| Екатеринбург и контекстное уточнение про Казань | Оба вопроса проверены в одном диалоге на публичной версии Vercel. Температура, условия и ветер сверены с результатом MCP |
| Трассировка MCP | Для каждого города проверены отдельные аргументы и данные. История и выбор трассировки доступны после обновления страницы |
| Недоступность MCP | На закрытом порту проверены HTTP 503, ошибка в чате и трассировке и отсутствие погодного ответа. Кнопка «Повторить» выполнила один повтор |
| Дизайн и мобильная версия | При размере 1176 × 826 px интерфейс помещается в один экран. На ширинах 320 и 390 px трассировка под чатом, горизонтальной прокрутки нет |
| Production-сборка | Локальная сборка и TypeScript прошли с одним воркером. Деплой Vercel завершился успешно |
| Публикация новой версии | [Приложение на Vercel](https://ai-meteoagent-lesson9.vercel.app/) проверено в чистом браузерном сеансе без входа |
| PDF со скриншотами и Google Drive | Восемь страниц и семь снимков, включая отдельно подписанный тест ошибки. PDF в папке «Занятие 9» |
