# Проверка требований ДЗ Light

| Требование | Результат |
|---|---|
| Готовый Open-Meteo MCP | `tools/list` вернул 12 инструментов с `weather.chukai.io/mcp` через официальный TypeScript SDK и Streamable HTTP |
| Облачный Tool Calling | В браузере подтверждена цепочка OpenAI Chat Completions → `geocode_location` → `get_weather_forecast` → ответ OpenAI |
| Екатеринбург и контекстное уточнение про Казань | Оба вопроса проверены в одном диалоге через OpenAI API. Температура, условия и ветер сверены с результатом MCP |
| Трассировка MCP | Для каждого города проверены отдельные аргументы и данные. История и выбор трассировки доступны после обновления страницы |
| Недоступность MCP | На закрытом порту проверены HTTP 503, ошибка в чате и трассировке и отсутствие погодного ответа. Кнопка «Повторить» выполнила один повтор |
| Дизайн и мобильная версия | Сохранены оформление, чат и схема MCP. При ширине 390 px трассировка расположена под чатом без горизонтальной прокрутки |
| Production-сборка | `npm run build` с настроенным ключом прошла с одним воркером, включая проверку TypeScript. Главная страница открылась в браузере |
| Публикация новой версии | После локального прогона и отдельного согласования |
| PDF со скриншотами и Google Drive | После согласованной публикации и проверки production |
